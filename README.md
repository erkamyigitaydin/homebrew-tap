# erkamyigitaydin/tap

Homebrew tap for [Damla](https://github.com/erkamyigitaydin/Damla), a notch companion for macOS 26+.

```sh
brew install --cask erkamyigitaydin/tap/damla
```

The cask is updated automatically by Damla's `release.sh` on every release. Damla updates itself with Sparkle after installation.
